# Pilot feedback log

Use this folder during Block 1 (Months 4–5) to capture friction from internal testers.

## Ideal pilot org profile

Do **not** start with the largest, most political, or most legacy-customized association.

| Attribute | Why |
|-----------|-----|
| Medium complexity | Enough realism without chaos |
| Cooperative staff | Faster iteration |
| Event-heavy | Immediate visible value |
| Spreadsheet pain today | Imports shine |
| No massive GL edge cases | Avoid accounting traps |

See [REALIZATION-PLAN.md](../REALIZATION-PLAN.md) (Pilot profile).

## Suggested format per session

```markdown
## YYYY-MM-DD — [Persona: e.g. events coordinator]

**Tasks attempted:**
1. …
2. …

**Friction (ranked):**
1. …
2. …

**Verbatim quotes:**
- "…"

**Follow-up:** issue / PR / won't fix (reason)
```

## Starter task scripts (5)

1. Add a new member with tags and a staff note (&lt; 2 min goal).
2. Publish an event and copy the public registration link (&lt; 3 min goal).
3. Find an existing member, open profile, review registrations.
4. Run a free public registration; check in attendee at event.
5. (Paid path) Complete one paid registration on staging; confirm status in admin and exceptions queue if email fails.
