# Quake OS Apps Map

PulsePoint AMS lives at the **repo root** (Next.js). This folder documents surface boundaries.

| App | Path in repo | Role |
|-----|--------------|------|
| **AMS** | `/` (Next.js) | Core association management |
| **Admin** | `app/[orgSlug]/(admin)/` | Staff console |
| **Portal** | `app/[orgSlug]/(portal)/` | Member-facing |
| **API** | `app/api/` + `packages/api/` | REST + webhooks |
| **Marketing** | `app/(marketing)/` | Public site |

Quake OS orchestrates improvements across all surfaces.
